# Screen Translator 0.4.0

Исправления по проверке версии 0.3.0 на телефоне.

## Что изменено

- Режим «Снимок», его диалог и верхняя панель полностью удалены. Управление перенесено в уведомление: «Пауза / Продолжить» и «Выключить».
- Остаётся одно окно перевода. Оно всегда NOT_TOUCHABLE, NOT_FOCUSABLE и находится ниже клавиатуры. Прозрачность ограничена значением ниже системного максимума с запасом; пустое окно скрыто.
- Язык результата исключён из источников. Неопределённый язык больше не подменяется единственным выбранным источником. При неоднозначном определении строка пропускается.
- Для русского и других выбранных языков на кириллице добавлена независимая проверка изображения строки через Tesseract eng+rus: латинский ML Kit OCR сам по себе не может надёжно отличить русский текст, ошибочно прочитанный латиницей. Проверка работает локально; модели упакованы в APK.
- Строки с символами целевого нелатинского письма пропускаются, включая смешанные строки. Это консервативное поведение: часть английского в одной строке с русским тоже может остаться без перевода.
- Определение языка, проверка изображения строки и переводы кэшируются. Успешный перевод сохраняется в кэш даже при смене кадра; его старые координаты не публикуются.
- Обработка идёт по строкам, первые результаты публикуются небольшими порциями. Не нужно ждать перевода всего экрана. Время обработки входит в период обновления: целевой период 120 мс для изменённого кадра и 260 мс для неизменного, минимальная пауза 16 мс. Эти интервалы не являются обещанием такой скорости OCR на телефоне.
- Для неизменного изображения повторные OCR и перевод не выполняются. ImageReader удерживает только последнее изображение и может повторно отдать статичный экран без ожидания несуществующего нового кадра.
- Системные панели исключены из распознавания; область клавиатуры исключается, когда Android сообщает её отступы.
- При завершении MediaProjection ресурсы освобождаются, остаётся уведомление с кнопкой «Возобновить». Оно открывает новый системный запрос разрешения; старый токен не переиспользуется.

## Ограничения

Android может завершить MediaProjection при запуске другой записи экрана, блокировке или остановке через системный интерфейс. Независимая системная запись и текущий способ захвата переводчика не могут гарантированно работать одновременно. Возобновление требует нового согласия пользователя. Причину конкретного onStop API не сообщает.

Обычное окно поверх приложений не даёт гарантированного прохождения нажатий в приложениях, которые намеренно запрещают касания через сторонние наложения. В таком приложении можно поставить перевод на паузу из уведомления: окно будет скрыто. Защитные настройки чужих приложений не отключаются.

ML Kit OCR не поддерживает все языки переводческих моделей. Дополнительная проверка кириллицы служит запрету ошибочного перевода, а не заявлению поддержки русского как исходного OCR-языка. Неуверенные, смешанные или очень короткие строки могут оставаться без перевода. Для целевых языков на латинице решение зависит от уверенности определения языка.

Первая проверка нового текста и загрузка OCR в память могут занять больше времени, чем повторный кадр. Действительная скорость, нагрев, повороты и нажатия требуют проверки на телефоне.

Исходный текст может частично просвечивать: непрозрачность обычного окна ограничена Android для прохождения нажатий. Режим остановленного изображения удалён по запросу.

APK остаётся debug-сборкой. Постоянная подпись обновлений пока не настроена. При несовпадении сертификатов Android откажется обновлять старую установку; автоматическое удаление приложения и его данных не производится.

## Проверки

GitHub Actions выполняет:
- JUnit: очередь моделей, поколения кадров, геометрия, исключение целевого/неопределённого языка, интервалы и безопасная прозрачность.
- Android lint и сборку APK.
- Проверки на эмуляторе Android 14: распознавание кириллицы на светлом/тёмном фоне, сохранение английских строк, повторное получение неподвижного изображения.

Результаты конкретного коммита доступны в [Actions](https://github.com/arc6323/Screen-Translator/actions). Эмулятор не заменяет проверку жестов, прошивки TECNO и записи экрана на реальном устройстве.

## Воспроизводимость

Gradle 8.10.2 закреплён wrapper и проверкой дистрибутива. Tesseract4Android 4.9.0 берётся из ограниченного по группе репозитория JitPack. Две модели tessdata_fast закреплены ревизией 87416418657359cb625c412a48b6e1d6d41c29bd и проверяются по Git blob ID при сборке. На телефоне эти модели не скачиваются; никаких внешних запросов для проверки кириллицы нет. Лицензия и сведения об источниках включены в assets/ocr-guard.
