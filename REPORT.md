# Screen Translator — технический отчёт

Дата: 13.09.2026

## 1. Назначение

Screen Translator — Android-приложение для распознавания текста на экране, определения языка и локального перевода поверх исходного приложения. Основной сценарий: русский язык телефона, перевод иностранного текста на русский без отправки распознанного текста на внешний сервер.

## 2. Текущая архитектура

- Android application, package `com.arc6323.screentranslator`.
- Target SDK 35, Min SDK 26.
- ML Kit Text Recognition для OCR.
- ML Kit Language Identification для определения исходного языка.
- ML Kit Translation 17.0.3 для локального перевода.
- MediaProjection + ImageReader для получения кадров экрана.
- `TYPE_APPLICATION_OVERLAY` для вывода перевода поверх других приложений.
- Foreground Service типа `mediaProjection` для Android 14+.
- Кэш языковых моделей через `RemoteModelManager`.

## 3. Исправления текущей версии

### Кэш языков

- Русский добавлен как обязательная модель по умолчанию.
- English отображается как встроенный/готовый язык ML Kit, а не как ложная загрузка 30 МБ.
- Для остальных языков добавлен выбор, отдельная кнопка скачивания и удаление уже скачанной модели.
- В меню показывается ориентировочный размер модели: около 30 МБ.
- Добавлена последовательная очередь загрузки.
- Добавлена кнопка «Пауза». Важное ограничение ML Kit: Android RemoteModelManager не предоставляет API для остановки уже начатой загрузки. Поэтому пауза останавливает очередь после текущей модели; активная загрузка завершается сама.
- Внутренний индикатор больше не показывает ложные 0% во время всей загрузки. Для активной модели используется indeterminate-индикатор; после завершения отображается фактический результат по моделям.
- Системное уведомление Android продолжает показывать реальный прогресс загрузки файла.

### Live-перевод

- Overlay теперь временно скрывается перед захватом кадра. Это устраняет главный цикл, когда OCR распознавал собственный перевод приложения и переводил его снова.
- Уменьшено количество обрабатываемых строк за кадр.
- Отфильтрованы слишком короткие OCR-фрагменты и строки без достаточного количества букв.
- Повторная загрузка одной и той же пары перевода предотвращается через кэш готовых пар и состояние подготовки модели.
- Интервал анализа уменьшен для более отзывчивой работы.
- Модель пары загружается до вызова `translate()`.

### Положение и внешний вид перевода

- Overlay учитывает соотношение размера захваченного кадра и размера окна overlay.
- OCR-прямоугольник слегка расширяется, чтобы исходный текст был полностью закрыт.
- Размер шрифта автоматически подгоняется под исходную строку.
- Используется системный sans/Roboto, чтобы приблизиться к типичному Android-шрифту.
- Цвет текста выбирается по яркости фона.
- Фон для закрытия исходного текста вычисляется по краям OCR-области.

## 4. Почему раньше были видны ошибки на скриншотах

1. Внутренний прогресс не мог показать байты загрузки ML Kit, поэтому экран оставался на 0%, а после завершения сразу переходил на 100%.
2. Overlay попадал в следующий захватываемый кадр. OCR видел собственные переводы, поэтому появлялись повторные, наложенные и искажённые переводы.
3. Старый алгоритм рисовал перевод слишком крупным и с прямоугольником, который не всегда полностью закрывал исходный текст.
4. Интерфейс выбора языка показывал выбранность отдельно от фактического состояния модели, из-за чего незагруженный русский выглядел уже отмеченным как готовый.

## 5. Ограничения

- ML Kit не предоставляет Android-приложению RemoteModelManager полноценный байтовый progress callback. Поэтому точный процент именно ML Kit-загрузки нельзя честно вывести из API. Системное уведомление загрузчика Android при этом может показывать реальный прогресс.
- ML Kit-модели имеют размер порядка 30 МБ каждая; фактический размер может отличаться.
- Полная одновременная работа двух независимых MediaProjection-сеансов (например, обычной записью экрана другого приложения и этим переводчиком) ограничена Android. Для режима одновременной записи + перевода на произвольном экране потребуется отдельная архитектура на базе AccessibilityService для приложений, где текст доступен через accessibility-дерево. Для видео/изображений OCR всё равно потребуется MediaProjection.
- Качество OCR и перевода зависит от качества исходного текста, масштаба, контраста и конкретного языка.

## 6. План следующего тестирования

1. Установить новый debug APK.
2. Открыть меню языков и убедиться, что русский показывает «Не скачан», если модель отсутствует, а English — «Встроен • готов».
3. Скачать русский и проверить, что индикатор не застывает на ложном 0%.
4. Скачать дополнительный язык и проверить последовательную очередь.
5. Проверить паузу: текущая модель должна завершиться, следующая — не стартовать до продолжения.
6. Запустить Live-перевод в Chrome на английском тексте.
7. Проверить, что исходный английский текст закрывается, перевод не дублируется сам собой и позиция совпадает со строкой.
8. Проверить скорость переключения между несколькими абзацами.
9. Отдельно проверить конфликт с записью экрана.

## 7. Итог

Проект находится на стадии функционального прототипа, но основные компоненты уже работают: запуск приложения, кэширование моделей, OCR, определение языка, локальный перевод и overlay. Текущий цикл исправлений направлен прежде всего на стабильность Live-перевода, устранение OCR feedback loop и нормальное управление языковыми моделями.
