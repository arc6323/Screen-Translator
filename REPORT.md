# Screen Translator 0.5.0

Изменения по скриншотам и проверке версии 0.4.0 пользователем.

## Что видно на скриншотах

Перевод заметно мельче исходного текста, длинные фразы обрезаны многоточием, оригинал просвечивает под переводом. Некоторые строки не переведены. По статичным изображениям нельзя измерить задержку или доказать поведение во время прокрутки; эти проблемы описаны пользователем. В панели языков русский действительно обозначен скачанным, а не встроенным.

## Исправления

- Касание сразу очищает координаты и перевод предыдущего экрана. Прозрачное окно 1×1 получает только ACTION_OUTSIDE и не перехватывает, не записывает и не воспроизводит жест. Видимое окно перевода остаётся NOT_TOUCHABLE, ниже клавиатуры, с непрозрачностью меньше системного предела. Нулевой alpha окна наблюдения не повышает суммарную непрозрачность.
- Перевод возобновляется после 400 мс от касания и 240 мс без заметного движения изображения. Новое движение продлевает ожидание. Это ожидание визуальной остановки, а не распознавание отпускания пальца: ACTION_OUTSIDE не содержит MOVE/UP.
- Детектор движения теперь проверяет и области текста: прежнее исключение всех переведённых прямоугольников могло скрыть прокрутку. Сетка увеличена с 24×40 до 80×144, сравниваются последовательные кадры. Собственная перерисовка кратко подавляет детектор и задаёт новый эталон. Системные панели/клавиатура остаются исключены.
- Нет постоянного цикла скрытия и повторного распознавания неподвижной страницы. Новый анализ вызывается касанием, изменением картинки, отступов или размера экрана; при ошибке выполняется повтор. Старые результаты не возвращаются после смены поколения кадра.
- Затемнение остаётся при касании, ожидании перевода и захвате OCR. При паузе или выключении затемнение убирается. Надписи скрываются отдельно от фона, поэтому фон не мигает между захватами.
- Размер шрифта вычисляется по высоте видимых символов оригинала, а не через уменьшение размера до вмещения строки. Используется свободное место справа и до следующей распознанной строки. Непереведённые строки также ограничивают доступное место. Подложка занимает только исходный текст и фактическую ширину перевода.
- Английский → русский работает на встроенной квантованной модели OPUS-MT. Модель и токенизатор входят в APK; после установки сеть для этой пары не нужна. UI помечает русский встроенным и не запускает для него ML Kit download.
- Другие выбранные языки → русский используют ML Kit исходный язык → английский, затем встроенный английский → русский. Для них загружается модель исходного языка. Другие целевые языки продолжают использовать ML Kit.
- Нативный перевод выполняется группами до четырёх строк; первые результаты показываются по готовности. Неактуальные задания пропускаются до запуска и прерываются между шагами декодирования. Кэш переводов повторно используется при возвращении к знакомому тексту.
- Сохранены фильтрация целевого языка, локальная проверка кириллицы, управление через уведомление и восстановление после остановки MediaProjection.

## Встроенные ресурсы

OPUS-MT Helsinki-NLP/opus-mt-en-ru, квантованная ONNX-конверсия Xenova/opus-mt-en-ru закреплена ревизией `e050376e960175e8ddc5cff85025dc8436cddd68`. Суммарно модели занимают 110 560 022 байта и токенизатор 7 205 388 байт до упаковки. Это увеличивает APK и расход памяти, но устраняет первоначальное скачивание русского на телефоне. Лицензия Apache-2.0 и атрибуция включены в assets/russian. ONNX Runtime Android 1.22.0. При сборке Python 3 преобразует проверенный токенизатор в индексированное дерево; телефон читает компактный двоичный файл без разбора JSON и создания десятков тысяч словарей.

Gradle 8.10.2 закреплён wrapper. Все три русских ресурса проверяются SHA-256 при сборке. Tesseract eng+rus закреплены ревизией `87416418657359cb625c412a48b6e1d6d41c29bd`, проверяются по Git blob SHA, уже встроены в APK. Неполные скачивания моделей не попадают в сборку.

## Проверки

GitHub Actions: JUnit для очереди загрузок, геометрии, целевого языка, поколений кадров и ожидания остановки; Android lint и сборка. Android 14 x86_64 emulator: встроенный перевод четырёх фраз с выключенными Wi-Fi/мобильными данными, сравнение токенизации с эталоном, касание через наложение в Activity другого UID, очистка надписей, размер букв и сохранение затемнения, проверки кириллицы и повторное чтение статичного экрана, непрерывное обнаружение последовательных перемещений.

Результаты конкретного коммита доступны в [Actions](https://github.com/arc6323/Screen-Translator/actions). Эмулятор не заменяет проверку на TECNO: скорость, нагрев и поведение системных окон зависят от устройства. Внешняя запись экрана на устройстве пока не проверена.

## Ограничения

- OCR не знает исходный шрифт: высота оценивается по распознанным границам, точное совпадение гарнитуры не гарантируется. Длинный перевод при недостатке места всё ещё обрезается; текст соседних строк не должен перекрываться.
- Неуверенные, короткие и смешанные строки могут пропускаться, чтобы не переводить уже русский текст, ошибочно распознанный латиницей. Это консервативная защита, а не полноценный русский OCR-источник.
- Первое открытие модели и новый OCR занимают время. Порог ожидания остановки не равен полной задержке перевода. Мелкие автономные изменения ниже порога детектора могут потребовать касания для обновления. Долгое неподвижное удержание пальца не определяется как отдельное состояние.
- Оригинал может частично просвечивать: Android ограничивает непрозрачность обычных окон, через которые проходят касания. Приложения, намеренно запрещающие сторонние наложения, могут блокировать их; защитные настройки не обходятся.
- Android может остановить MediaProjection при другой записи экрана или блокировке. Уведомление «Возобновить» запрашивает новое системное разрешение; старый токен не переиспользуется.
- APK остаётся debug-сборкой. Постоянный ключ подписи между сборками не настроен. При несовпадении сертификата Android не установит обновление поверх прежнего приложения. Данные пользователя автоматически не удаляются.
